NEOVIM MANUAL                                                         *manual*

Open this page with `<Space>?` or `:help manual`.

`<Space>e` means press Space, then e. `<C-o>` means Ctrl+o. `<CR>` is Enter.
Anything starting with `:` is typed and run with Enter. Keys work from normal
mode unless stated, so press `<Esc>` first if in doubt.

Press `<C-]>` on a link to follow it, and `<C-o>` to come back.

JOT DOWN A QUICK NOTE                                            *manual-note*

>
    nvim              an unnamed scratch buffer
    nvim notes.txt    a named file
<
To                                          Press~
Start typing                                `i`
Stop typing                                 `<Esc>`
Save                                        `:w`
Save a scratch buffer under a name          `:w ~/notes.txt`
Save and quit                               `ZZ`
Quit and discard                            `:q!`
Copy a line                                 `yy`
Copy a selection                            `v`  move  `y`
Select whole lines instead                  `V`
Paste                                       `p`
Undo, redo                                  `u`  `<C-r>`
Find text                                   `/text`  then  `n`  `N`
Clear the search highlight                  `<Esc>`
Rewrap a paragraph                          `gqap`
Start another empty buffer                  `:enew`

- Copy and paste share the system clipboard: `yy` here pastes with Cmd+V
  elsewhere, and `p` pastes what you copied elsewhere.
- Undo history survives closing the file.
- A lowercase search ignores case. One capital letter makes it exact.
- Lines wrap at 120 characters as you type.
- Words already in the file are offered as you type: `<C-y>` accepts,
  `<C-e>` dismisses.
- Brackets and quotes close themselves. Type the closing character to step
  over it. Backspace on an empty pair removes both.

READ AND EDIT JSON OR YAML                         *manual-json* *manual-yaml*

Errors show at the end of the offending line as you type. That needs Node.
Without it you still get colours, folding and indent.

To                                          Press~
Format the file, or expand minified JSON    `<Space>f`
Jump to the next, previous error            `]d`  `[d`
Read the full error                         `<C-w>d`
List every error in the file                `<Space>q`  then  `<CR>`  jumps
Outline of keys                             `gO`  then  `<CR>`  jumps
Fold or unfold the block under the cursor   `za`
Fold everything, unfold everything          `zM`  `zR`
Jump to the matching bracket                `%`
Select the value under the cursor           `van`
Grow, shrink that selection                 `an`  `in`
Indent, dedent a line                       `>>`  `<<`
Indent, dedent a selection                  `>`  `<`
Comment a YAML line                         `gcc`
Move through completions                    `<C-n>`  `<C-p>`
Accept a completion                         `<C-y>`

- Saving does not reformat these files. Only `<Space>f` does.
- Indentation follows the file you opened. New files use two spaces. If the
  guess is wrong, run `:GuessIndent`.

KEEP IT UPDATED                                                *manual-update*

To                                          Do~
Update plugins                              `<Space>pu`
Update language servers and tools           `:MasonToolsUpdate`
Edit this config or this manual             `<Space>sn`

A plugin update opens a list of changes. `:w` applies them and `:q` discards
them. Run `:restart` afterwards, then commit nvim-pack-lock.json.

To undo a bad plugin update, restore nvim-pack-lock.json from git, run
`:restart`, then: >vim
    :lua vim.pack.update(nil, { offline = true, target = 'lockfile' })
<

REQUIREMENTS                                             *manual-requirements*

Plugins, language servers and parsers install themselves on first launch.
The machine has to provide:

- Xcode Command Line Tools, for git and a C compiler.
- A Nerd Font in the terminal, for icons.
- ripgrep, for `<Space>sf` and `<Space>sg` outside git repositories. Without
  it, both still work inside a git repository.
- Node, for JSON and YAML errors, formatting and completion.
- Gleam, for Gleam files.

Without Node or Gleam, that language falls back to colours, folding and
indent.
